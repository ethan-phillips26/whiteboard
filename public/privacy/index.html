Privacy

Whiteboard and the Whiteboard Connector · effective 15 Sep 2026

Whiteboard reads your Blackboard courses inside your own browser. Nothing it reads is sent to the developer or to any server of Whiteboard's — there isn't one. It never submits, posts or changes anything on Blackboard.

What Whiteboard is

Whiteboard is a read-only dashboard for Blackboard Learn, made of two parts: the website at ethanphillips.dev/whiteboard, which is a set of static files hosted on GitHub Pages, and the Whiteboard Connector browser extension, which makes the requests to Blackboard on the website's behalf. It is an independent project, not affiliated with or endorsed by Blackboard or Anthology.

What it reads

Only from the one Blackboard address you connect, and only while you are signed in to it in the same browser. It uses the Blackboard session your browser already has; it never asks for, sees or stores your Blackboard password.

  • your name and Blackboard user ID;
  • your courses and their terms;
  • each course's gradebook: its items, categories and your own grades;
  • course content, announcements, and the files attached to them when you open or download one;
  • your own attempts at an assignment — their status, grade and the instructor's feedback.

Every request is a read (GET). The extension only allows requests to Blackboard's public REST API (/learn/api/public/) and its course-file links, and refuses anything else.

Where it is kept

On your device, in your browser, and nowhere else:

  • The website's browser storage (an IndexedDB database named whiteboard): a copy of what was read, so the dashboard opens quickly and asks Blackboard again only once an entry is out of date; corrections you make, such as an edited due date or grade weights; and which announcements have already been shown to you.
  • Small preferences (localStorage): your light or dark choice, when you last read the announcements, and the Blackboard address you last entered, so the sign-in screen can fill it in.
  • The extension's storage: the Blackboard address you connected, and the address of any file-storage server a download was found to need.
  • Files you open or download are held in the open tab's memory and are gone when you close it, unless you save them.

Demo mode uses made-up data, kept in a separate database (whiteboard-demo), and contacts no Blackboard at all.

There are no accounts, no analytics, no advertising and no tracking. Nothing is sold or shared.

Who else is involved

  • Your school's Blackboard receives the requests, just as it would if you were using Blackboard itself.
  • Blackboard's file storage — for example *.content.blackboardcdn.com or *.blackboard.com — serves a file when you open or download one, because Blackboard redirects file links there.
  • GitHub hosts the website, and like any web host receives ordinary request information, such as your IP address, when the page loads. See GitHub's privacy statement.
  • Google Fonts serves the website's typefaces, so your browser requests them from Google, which receives your IP address. See Google's privacy policy.

The extension itself contacts only the Blackboard address you connected and its file storage.

The extension's permissions

  • Access to your Blackboard address and its file storage — asked for when you press “Allow access”, and only for the address you enter.
  • Storage — to remember that address.
  • Declarative net request — removes the Origin header from the extension's own requests to Blackboard, which refuses requests that carry a foreign one.
  • Web request — notes where a file download is redirected, so that when a file cannot be fetched the extension can say which server it needs permission for.

The extension does not read or store cookies or passwords, and it answers only the Whiteboard page at ethanphillips.dev/whiteboard.

Removing your data

  • Log out (or Exit demo) in Whiteboard clears everything the website stored about your coursework, including your corrections, and takes back the extension's access to Blackboard.
  • Settings → reset clears the stored coursework and corrections without disconnecting.
  • Removing the extension deletes its storage.
  • Clearing this site's data in your browser removes the rest, including your theme choice and the remembered Blackboard address.

Signing out of Blackboard itself is done on Blackboard.
